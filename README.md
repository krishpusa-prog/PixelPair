# PixelPair
“A fully offline, privacy-preserving visual product comparison engine that performs real-time similarity search directly in the browser using on-device ML — eliminating cloud dependency, reducing cost, and ensuring data privacy.”

# 🔥 Highlight:

-->No API calls
-->Zero server cost
-->Works offline
-->Privacy-first
